## Signing a Contract

Contract artists apply via the **Artist Contract Portal:**
**https://manilla-contract.netlify.app**

The portal guides artists through a 5-step process:
1. Identity verification
2. Email OTP
3. Artist profile
4. 360° Agreement review + e-signature
5. Review & submit

Application IDs follow the format: `MC-YYYY-XXXXXXXX`
